## Integer Data Types 
* **Signed**
    * char/int8_t : signed integer 8 bites long
        * max is 127
    * int/int32_t : 32 bit integer
        * can store up to 2 billion
    * long long int/int64_t
        * can store a number up to 9 quintillion

* **Unsigned**
    * unsigned char/uint8_t 
        * max is 255
    * unsinged int/uint32_t
        * mac is 4 billion
    * unsigned long long int/uint64_t
        * max is 18 quintillion

* these named (uint8_t) integers are defined in <stdint.h>


## Storing numbers as 64-bit number in memory
* **Little Endian** store LSB first
* **Bit Endian** store MSB first
* Hex helps humans read multi-byte ints
    * group into 4-bit groups
