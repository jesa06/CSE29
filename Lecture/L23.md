## Network Congestion
> if we have more than one user, we are likely to encounter this

* **router** is a computer, another host in a way, looks at message and finds out which *link* we should send the message to bring it to its final destination
    * opportunity for congestion, they can get *overwhelmed*
    * too much data can be sent through this link and we would not be able to know
* multiple sending hosts send packets through a link slower than their combined speed
* this leads to packets being dropped (web page does not load)

## Avoid congestion
> TCP Avoids Network congestion

* detect link is overwhelmed --> make it slow down
* host sending data realizes the host is not acknowledging data, it is dropping packets --> slow down

1. all hosts independently probe the network to determine how much bandwidth is available
2. assume packet loss implies congestion
3. slow down sending packets when congestion is detected
