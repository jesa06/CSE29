# Lecture 7
> Pointers: a variable in C that can store the address of another variable or function

```C
char num[] = {42};
char* pnum = num;
assert(pnum[0] == 42);

```

* when you store a variable, it is stored in memory
* memory is like a linear space
* pointers need memory to store pointers
* address in memory is a **byte address** 

## Layout of arrays and other variables in memory
* **Variable**: A region of memory allocated to a single value of a specific data type
* **Array**: A region of memory allocated to a set of values of a specific data type

```C
char arr[] = {4, 5, 6};
char c = '!';
```

## Array variables are always pointers
* when you declare array, it is a POINTER not an array 
* %p prints the POINTER in hexadecimal notation to tell us address of where something is stored  (tells us the beginning of where the array is)

```C
char arr[3] = {4, 5, 6};
printf("arr=%p\n", arr); 

```

* contiguous region of memory
* we add to the pointer to do indexing in the array 
* when you do an array index (arr[3]) the compiler will do pointer math
    * arr + (3 & sizeof(long int))
* let's us directly read AND MODIFY arrays in place 

## Special C syntax for pointers

* & - give me address of variable
* * - tell computer to go to that address and READ the value 
    * dereference, get VAR at address

* no matter what you do to the pointer (cast, turn into different data type), the data stays the same
