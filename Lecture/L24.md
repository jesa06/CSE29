## Socket libraries
* socket- when you plug one thing into another thing, it is like plugging into a socket
* **socket(AF_INET, SOCK_STREAM, 0)** 
    * gets us access to internet
    * opens the ability to connect to the internet, creates a socket

## System Calls
* system calls to connect to internet
    * **bind()**
        * *flag* **INADDR_ANY**- means let ANYONE connect
        * *port* unique number 
    * **listen()** listens for incoming connections from cpu on internet to this software
        * waits and listens
    * **accept()** to accept a new connection from another user
    * **recv(socketToUser, buffer, BUFFER_SIZE - 1, 0)** receives/read data from another computer
        * instantiation where we receive bytes, *remote memory copying*

## Function pointer

# Discussion: HTTP 
> HTTP is the user interface, the most surface layer in the **OSI Model** (Open Systems Interconnection)


## HTTP (hypertext transfer protocol)
> transfer data between clients and servers and vice versa

* client initiates request

### 4 main components of Request Structure
1. Request line
    * GET, POST, DELETE, PUT, Patch
2. Headers
    * info about destination and what payload/data is being set
3. Empty line
4. Body
    * optional 

### 4 main components of Response Structure
1. Status line
    * 2xx success
    * 3xx redirection
    * 4xx client error
    * 5xx server error
2. Headers
3. Empty line
4. Body
