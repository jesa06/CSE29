## Socket libraries
* socket- when you plug one thing into another thing, it is like plugging into a socket
* **socket(AF_INET, SOCK_STREAM, 0)** 
    * gets us access to internet
    * opens the ability to connect to the internet, creates a socket

## System Calls
* system calls to connect to internet
    * **bind()**
        * *flag* **INADDR_ANY**- means let ANYONE connect
        * *port* unique number 
    * **listen()** listens for incoming connections from cpu on internet to this software
        * waits and listens
    * **accept()** to accept a new connection from another user
    * **recv(socketToUser, buffer, BUFFER_SIZE - 1, 0)** receives/read data from another computer
        * instantiation where we receive bytes, *remote memory copying*

## Function pointer
> implemented in web servers to leave it flexible for users
* (*handler)(buffer, client_sock)
    * a function call, *handler* while dereferencing it --> **function pointer**
    * a function you do not have to implement at the time you compile the code, just have address where you expect it to be 
```c
void (*handler)(char *request, int client) {
    printf("Received request:\n%s\n", request);

    another_function(handler, param2)
```
