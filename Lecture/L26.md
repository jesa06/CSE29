## Introduction to Operating Systems
*An Operating System is the *program* on a computer that *runs user programs*
    ◆ Starts and ends program execution
    ◆ Switches between running programs
    ◆ Manages access to hardware (e.g., RAM and Disk) so they are shared across programs
* Topics covered in CSE 120 Operating Systems
    ◆ How does the Operating System start running?
    ◆ How does an Operating System run a program on a computer?
    ◆ How does an Operating System share access to hardware in the computer?
    ◆ How does a program ask the Operating System to do things for it?
    ◆ How does an Operating System allow programs to run independently of other programs?

## Booting an Operating System
* #1 hardware resource is the processor (intel, ARM)
* boots and immediately runs code,...where is that code?
* The OS Boots or "Picks itself up from its Bootstraps" when the computer powers on:
    * the CPU jumps to the first instruction when it is powered on
    * this code is called the **Bootloader*
        * BIOS (Basic Input/Output Systems)
        * UEFI (Unified Extensible Firmware Interface)

* The Bootloader reads teh OS's first chunk of instructions from a secondary storage into RAM
* Then it calls main() of the OS

## How does an OS run a program 
1. load binary from disk into RAM
    * wire *bus* sends a.out binary 
2. Create & init new process- processor reads instructions from the RAM
    * processor cannot directly run program from disk because it is too slow
    * has its own memory
3. Init CPU state to run process (CPU Registers Cache)
* hierarchy of how to read bits:
    * persistently story in disk even when powered off
    * RAM is faster but less space and when cpu is off it erases
    * SRAM is even smaller and even faster
