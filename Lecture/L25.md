## More about the web browser
* in order for website to give us something we send GET to the server
* client knows bc server prints back to the client, telling they are speaking in the same HTTP version as you
    * if send back "200 OK", it means things work --> **correctly pull code**
    * 404 is an error, make client web browser say it couldn't find what we are looking for
* web browser knows what to expect:
    * "Content-Type: text/plain"
* in between "\r\n"
    * like a typewriter, character return and new line, shifting over and new line
    * new lines separate headers 
    * "\r\n\r\n" means *here comes the data*
