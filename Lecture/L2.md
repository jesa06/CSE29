## UTF-8
> represent characters outside of English letters

* ASCII is only English letters (and unsigned)

* 256 bit patterns (one byte) is not enough to represent all characters!


* add more byte by setting specific bits to tell you there are more bytes, and how many more specifically
    * represented by negative numbers 
    * emojis take up 4 times amount of bytes
    * chinese characters are 3 bytes


## Printing binary representation of memory

* %u - unsigned int representation (4 byte/32 bits)
* %b - binary representation (4 bytes of bits)
    * shows up with a lots of bits prepended by 1's
* %hhb - prints only single byte (hh is half half of 4 = 1)
    * prints the same as %b WITHOUT the prepended 1's
* %hhu - single-byte unsigned char as a number 

* ASCII doesn't activate the highest byte
    * if it starts with 1, you are no longer in ASCII

## Negative Integers in Computers

* integers are stored as binary numbers (unsigned)
* must encode somehow in the binary digits that a number is negative

### Two's complement signed 
* max 127
* highest order bit is -128 or -2^7

| MSB | | | | | | | LSB |
| - | - | - | - | - | - | - | - | 
| -128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

### Two's complement unsigned
* max 255

| MSB | | | | | | | LSB |
| - | - | - | - | - | - | - | - | 
| 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |


## sign extension
* when wanting to add a byte and keep the number negative, add 1's in front of the bites
