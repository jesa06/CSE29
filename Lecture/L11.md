```c
#include <stdio.h>
#include <string.h>

// explore strtok

int main() {
  char str[] = "Aaron Schulman,schulman@ucsd.edu,Professor";
  printf("str@%p: %p \"%s\"\n", &str, str, str);

  char* a = strtok(str, ","); // Comma Separated Vector
  char* b = strtok(NULL, ",");
  char* c = strtok(NULL, ",");
  char* d = strtok(NULL, ",");
                                         //&a is address of the pointer (show &a and a are different)
  printf("a@%p: %p \"%s\"\n", &a, a, a); // returns a pointer that points to the start of the first token "Aaron Schulman"
  printf("b@%p: %p \"%s\"\n", &b, b, b); // 0x16fdc710c schulman@ucsd.edu
  printf("c@%p: %p \"%s\"\n", &c, c, c);
  printf("d@%p: %p \"%s\"\n", &d, d, d);

}
```

* strtok() --> **string tokenizer** takes a string that is a *pointer* to a string, splits it into *substrings* using the token you pass into that field 
    * does not waste memory --> **reuses it**
    * finds token/substrings within a string
    * returns a pointer that points to the *start of the first token* (token is start of string BEFORE the comma)
* both strings point to same value of memory 
* what does it mean to tokenize a string:
    * replace comma with a NULL terminator
        * when finds comma, writes null terminator where comma was. creates a substring 
* sizeof() returns the size of the whole string
* strlen() counts bytes UNTIL null terminator 
    * str+strlen(str) + 1 helps us move PAST the null terminator 
* everytime you call strtok() it writes null terminator into first instance of token in the string...need to run strtok() again to get to the next instance
    * pass in the NULL pointer for next instances
    * don't have to do str+strlen(str) + 1 helps us move PAST the null terminator, it is built into the function 
* static means you use the same memory and therefore have the same value every time you run it in future

int parse_args(char* input, char** args) {
  char* current = strtok(input, " ");
  int current_index = 0;
  while(current != NULL) {
    args[current_index] = current;
    current = strtok(NULL, " ");
    current_index += 1;
  }
  return current_index;
}

# Lecture 12: Virtual Memory, Fork

## Fork
* returns one number in the process of call fork
* returns another number in the child 
    * two running processes...we need to know if we are in PARENT OR CHILD
* check if return value fork is 0
    * if 0 --> in child process
    * if !0 --> in parent process
    * return value is the identifying number of the child process
* parents need to know bc parent may want to do something to fork child
    * ex. wait till child is done then parent can do the next thing

```c
#include <unistd.h>
#include <stdio.h>


int main() {
  int a = 100;
  printf("%d %p\n", a, &a);
  int pid = fork();
  if(pid == 0) { a = 999; }
  while(1) {
    printf("[%d]: %d %p\n", pid, a, &a);
  }
// Virtual Memory

  // What will this print?

  // 100 0xfff71234

  // A
  // 999 0xfff71234
  // 999 0xfff71234

  // B
  // 999 0xfff71234
  // 999 0xfff71900


}
```
* two variables (with diff values) with the **SAME ADDRESS**
* every process THINKS it controls whole memory space of computer BUT IN REALITY that is *virtual memory*
    * a way to protect programmers from themselves...   
        * prevent program from reading memory from other program 
        * isolates every program into its own memory space
    * processor (hardware in cp) designed to hold multiple running processes with different address
        * translates virtual address to real address
* we can't use the linear RAM space, we are using the *virtual memory spaces*
    * *advantage* let's you have memory that your computer actually has
    * address maps magically to somewhere in RAM
    * when you run out of RAM, it will be stored somewhere else automatically by your computer (running program does not know)
