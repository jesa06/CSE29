## Analyzing codepoints requires accessing individual bits in C data types

* possible to control/access individual bits of integer data types 
    * integer datatypes all can have bit-wise operations
* there are special mathematical operators in C for doing operations on bits
    * & **getter**
    * | **setter/turn on**
    * ^ **toggler/reverse bits**
    * >> 
    * <<

* Boolean operators work on all bits of a variable

## Bit shifting
* <<  (left shift)
    * move all bits over to left by X bits
    * pad with 0's on the empty right bit slots
    * in other POV multiply each '1' bit by 2, or moving over to higher-order bits
* >> (right shift) 
    * move all the bits over to the right by Y bits
    * padding the empty slots on the left side depends on the data type

* 0b00110001 << 2 = 0b11000100
* 0b00110001 << 3 = 0b10001000
    * it's possible some bits will fall off of the integer (exceeding value you can represent of that integer)
* 0b0011001 >> 2 = 0b00001100
