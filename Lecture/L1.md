##  How do computers store characters?

* infinite loop, 0 --> 1 --> 0 --> 1...
* turn off computer --> RAM is not stored

## How do we represent characters as bits?
* ASCII Encoding: [ 0-127 ] lowercase and uppercase

## How is a number represented?
* a number is an array of RAM cells with binary states
* 1 byte = 8 bits
* each bit has an order
    * most significant bit (left side)
    * least significant bit (right side)

## Live Coding

* character 0 or integer 0 tells us where the end of a string is (null character)
