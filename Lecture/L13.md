```c
#include <string.h>
#include <stdio.h>
#include <stdlib.h>


struct ArrayStruct {
    char data[26];
};

struct PointerStruct {
    char *data;
};

int main() {
printf("PART 1:\n");
struct ArrayStruct A1; // memory address 0000
strcpy(A1.data, "Original");

struct ArrayStruct A2 = A1; // memory address 1000

strcpy(A2.data, "Modified");
printf("A1 contains: %s\n", A1.data);
printf("A2 contains: %s\n", A2.data);

//-----------------------

printf("\nPART 2:\n");
struct PointerStruct P1; // address 0000
P1.data = malloc(20 * sizeof(char));
strcpy(P1.data, "Original");

struct PointerStruct P2 = P1; // allocated at address 1000

strcpy(P2.data, "Modified"); //p1.data and p2.data point to same memory bc only
                            // malloc once (only one allocated part of memory)

printf("P1 contains: %s\n", P1.data); 
printf("P2 contains: %s\n", P2.data);

//p1 and p2 point to same chunk of memory so they both (their .data) return "Modified"
}
```

* in the pointer struct the pointer points to a specific malloc() memory, you only malloc() once
* when you assign p2 to p1 it copies the memory address of the pointer to p2
    * p2.data points to the same part in memory

* when arrays are defined over specific size in a struct, they are allocated **IMMEDIATELY** within that struct, in the **SAME LOCATION OF MEMORY**

* struct is a template for FUTURE instantiations so you do not malloc() inside of a struct
