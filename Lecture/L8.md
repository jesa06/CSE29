## Hashing
> A way to fingerprint arbitrary bytes of data in memory

* taking some data (bits in memory of computer) produces an integer unique to that set of data

* let you treat memory as bits of data that you don't care what is actually stored in them 
* everything stored in the memory of a computer is just arrays of bytes

### how does hash connect to pointer
* relies on concept of pointer
* pass in a pointer (idc what it points to), hash this many bites --> tells unique contents of that pointer
* use hash to STORE PASSWORDS SECURELY
* *one way function*: goes from bits to integer not the other way around

## Functions
* strlen() counts num of bytes until null terminator
* sizeof() 
    * accepts data type or a **variable name**
    * returns the number of bytes in memory that the data type
```C
#include <stdlib.h>
#include <stdio.h>
#include <string.h>


int main(int argc, char** argv) {
    sizeof(uint32_t) returns 4

    uint32_t var = 0;
    (int) sizeof(var) // returns 4 bc 32 bits is 4 bytes

    uint32_t* ptr;
    (int) sizeof(ptr) // returns 8 bc size of a pointer in memory is 64 bits or 8 bytes

    uint32_t arr[5];
    (int) sizeof(arr) // returns 20 bc 4 bytes per each element (5) 
    // defined it as an array of size 5, so each element is uin32_t which is 4 bytes per element, so that is 20

    (int) sizeof(&arr) // returns 8 because a memory address is 8 bytes, which is same as the pointer 

    (sizeof(arr) / sizeof(uint32_t)) // = num bytes in array / size of each element in the array = length of the array
    (sizeof(arr) / sizeof(*arr)) // WORKS THE SAME BC: sizeof(*arr) dereferences arr , points to first element, size of first element, size of uint32+t


}
```

*  **CANNOT** return char array but can return a char pointer
